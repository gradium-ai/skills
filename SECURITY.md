# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through this repository's private
security-advisory flow instead of opening a public issue. If private reporting
is not yet enabled, email `support@gradium.ai` with “Security” in the subject.
Include the affected skill or script, impact, reproduction steps, and any
suggested mitigation.

Do not include live API keys, access tokens, private customer data, or working
public exploit infrastructure in the report. Revoke and rotate any credential
that may have been exposed.

## Scope

Security reports may cover the skill instructions, bundled scripts, generated
application patterns, credential handling, provider integrations, and build or
release automation on the default branch.
